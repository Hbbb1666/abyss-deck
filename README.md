# 深渊牌局 · Abyss Deck

一个**杀戮尖塔风格的肉鸽卡牌构筑游戏**，纯网页、手机竖屏优先，零框架依赖。

> 一副卡组，一条不归路。每走一层，都要在三张牌里挑一张。

## 怎么玩

### 方式零：直接打开单文件版（最省事）

```
dist/abyss-deck.html      # 约 0.81 MB，素材全部内联，零依赖
```

拷到手机/电脑上双击即玩，也可以直接发给别人（微信、网盘、群文件都行）。

### 方式一：开本地服务器用手机浏览器玩（推荐）

```bash
cd /sdcard/Download/roguelike
node server.mjs          # 默认监听 0.0.0.0:8765
```

然后在手机浏览器打开 **http://127.0.0.1:8765**

> 换端口：`PORT=9000 node server.mjs`

### 方式二：部署成网站（别人点链接就能玩）

把仓库推到 GitHub，`.github/workflows/deploy.yml` 会自动跑测试 → 构建 → 发布到 GitHub Pages。
另外在仓库 Settings → Pages 里把 Source 选成 **GitHub Actions** 即可。

任何静态托管都能用（Cloudflare Pages / Netlify / 自己的服务器…），因为整个游戏就是一堆静态文件。

## 装到桌面（PWA）

用 http(s) 打开游戏后，主菜单里有「**📲 安装到桌面**」：

- **安卓 / 桌面 Chrome、Edge**：弹出原生安装框，装完有图标、全屏、**离线可玩**
- **iOS Safari**：Safari 不支持自动安装，按提示点「分享 → 添加到主屏幕」
- 已经是独立窗口运行时不显示该入口

离线是靠 Service Worker 实现的：`sw.js` 会在安装时按 `precache.json`（构建期自动生成，
约 150 个资源）把精灵图、音效、字体一次性存进缓存，之后**断网也能完整游玩**。
`sw.js` 里的缓存版本号由 `npm run build` 按内容哈希自动盖戳（别手改），
这样每次发版都能让老用户的 SW 正常更新。

> 单文件版本身就是全内联的，天然离线；只是 `file://` 打开时浏览器不允许注册 Service Worker，
> 所以那种情况下"添加到主屏幕"只是建个快捷方式，不会变成独立应用。

## 玩法

| | |
|---|---|
| **目标** | 从地牢一路打到深渊之主，共 **3 层**，每层一个 Boss |
| **职业** | 铁誓骑士（力量/护甲）· 流亡法师（元素/群攻）· 暗巷游侠（中毒/连击） |
| **战斗** | 每回合 **3 点能量**、抽 **5** 张牌。点数用光就结束回合 |
| **出牌** | 点手牌即可打出。需要选目标的牌，会先让你点敌人（点战场空白处可取消） |
| **长按卡牌** | 放大看清效果 |
| **回合结束** | 手牌全部弃掉，**护甲也会清空**（除非有「壁垒」） |

### 敌人意图

敌人头顶的图标就是它**下一步**要做的事——先看意图再决定攻防：

| 图标 | 含义 |
|---|---|
| ⚔ 12 | 将造成 12 点伤害 |
| ⚔ 4×3 | 将攻击 3 次，每次 4 点 |
| ⛨ | 将获得护甲 |
| ⬆ | 将强化自身 |
| ↓ | 将施加负面状态 |
| ✚ | 将回复生命 |

### 状态效果

| 图标 | 名称 | 效果 |
|---|---|---|
| ⬆ | 力量 | 每次攻击 +N 伤害 |
| ✦ | 敏捷 | 获得的护甲 +N |
| ✸ | 易伤 | 受到的伤害 **+50%** |
| ↓ | 虚弱 | 造成的伤害 **−25%** |
| ☠ | 中毒 | 回合开始掉 N 血（**无视护甲**），然后 −1 |
| ✹ | 荆棘 | 被近战攻击时反弹 N 点伤害 |
| ⛨ | 不屈 | 每回合开始获得 N 点护甲 |
| ☯ | 仪式 | 每回合开始获得 N 层力量 |
| ▣ | 壁垒 | 护甲不再于回合结束时消失 |

### 地图节点

| 图标 | 类型 | 说明 |
|---|---|---|
| 铁栅栏 | ⚔ 战斗 | 普通敌人，给金币和卡牌奖励 |
| 恶魔脸 | 💀 精英 | 血厚伤害高，**必定掉遗物** |
| 石像鬼 | ❓ 事件 | 随机事件，可能是好事也可能是坏事 |
| 铁砧 | 🏪 商店 | 买卡牌 / 遗物 / 药水，还能花钱删牌 |
| 火盆 | 🔥 营火 | 回血 **或** 升级一张牌 |
| 宝箱 | 💎 宝藏 | 白送遗物或金币 |
| 大门 | 👑 Boss | 打赢进下一层 |

**进度自动保存在浏览器本地**，战斗中关掉页面再打开，点「继续游戏」会回到那场战斗，不会跳过。

### 数据驱动

加内容基本只需要改 `js/data/` 下的文件，不用碰逻辑：

```js
// 加一张卡
my_card: {
  name: '裂空斩', cls: 'knight', type: 'attack', rarity: 'rare', cost: 2, target: 'enemy',
  art: 'sword_broad', dmg: 15, up: { dmg: 20 },
  text: c => `造成 <b>${c.dmg}</b> 点伤害。`,
  fx: [{ t: 'dmg', v: 'dmg' }],       // v 写字段名，升级后数值自动同步
},
```

效果 DSL 共 18 种（`dmg` / `dmgAll` / `block` / `draw` / `buff` / `debuff` / `summon` / `addCard` …），
详见 `js/data/cards.js` 顶部的注释。

## 开发

> 改代码前请先读 **[docs/开发与维护指南.md](docs/开发与维护指南.md)** ——
> 里面有回合结算的确切顺序、加卡牌/敌人/遗物/事件各自要动哪些文件、
> 立绘与文案长短的硬性限制、存档读档必须重算的字段，以及**已知问题清单**。

```bash
npm ci                          # 一次性：装 jsdom + rollup
npm run build                   # 必须先构建，测试要读 dist/bundle.js
npm test                        # 跑测试（179 项）
npm run build:single            # 额外产出 dist/abyss-deck.html（素材全内联）
npm run serve                   # 本地起服务，手机同局域网可访问
```

`dist/` 不在版本库里，所以**先 `build` 再 `test`**，顺序反了会 ENOENT。

### 测试覆盖（179 项，全绿）

- **数据层**：61 张卡的文案/效果字段/立绘、24 种敌人的招式/AI/立绘/召唤目标、
  27 件遗物的图标与钩子方法、遭遇战配置、各职业奖励池
- **逻辑层**：120 场随机对局（0 崩溃 / 0 死循环）、61 张卡 × 升级前后逐张实测可打出、
  200 个种子的地图全部可通关且房间类型齐全、敌人意图与实际动作一致性
- **DOM 层**：jsdom 真实加载页面，走完 菜单→选职业→地图→战斗→打完→结算；
  商店/事件/营火/宝箱/奖励 五个房间全部渲染 + 点击不崩；12 个事件 × 全部选项 × 3 职业
- **PWA / 预缓存清单**：清单必须**恰好等于**发布目录里的 Web 资源（不多不少）、
  每条都能在磁盘上找到、且不混入 `node_modules`/`.git` 等非运行期文件；
  manifest 的 name/start_url/192+512 图标齐全且每个图标文件真实存在
  （这条是补的：`buildPrecache()` 曾把 1156 个 `node_modules` 文件写进清单，
  而它们并不在发布产物里 → 每个访客首开白跑一千多个 404）
- **存档往返**：地图坐标在 JSON 序列化前后都必须落在 0~1 范围内
  （这条是补的：之前 `layout()` 用对象引用找节点，读档后 52 个节点全跑到屏幕外）
- **地图语义**：200 个种子每张地图都必须**有且只有一个 Boss 节点**，且位于最后一行
  （这条也是补的：`add()` 的 `!n.type` 守卫把 Boss 类型静默吃掉了，导致打不通关）
- **选牌器（升级 / 移除）**：两条路径端到端跑通 —— 弹层按钮必须有文字、
  选卡进选中态、点「确定」后卡组**真的**升级/减少、再点一次已选中的牌能确认、
  没选卡点「确定」不会误删
- **战斗存档**：序列化 → 反序列化后敌人种类/血量、玩家血量、手牌内容、三个牌堆、回合数全部一致；
  真机上"关页面再进"实测连血量和能量都对得上
- **召唤归属**：召唤者死亡后小弟一并消失，且战斗能正确判定胜利
- **弃牌代价（飞刀）**：界面确实实现了 `requestDiscard`；玩家挑哪张就弃哪张；
  **取消弃牌也必须付出代价**（不能白赚）；界面没接回调时空转不了；手牌空时不卡死
- **存档版本兼容**：版本不认识的快照必须被**拒绝**而不是静默变成空战场 ——
  否则 `resume()` 会把"读档失败"当成"敌人全死"直接判玩家胜利（白送一关）；
  player/enemies 残缺、defId 全部无法解析等情况一律拒绝并改为重开这场战斗
- **监听器回收**：来回切 5 轮战斗/地图，window/document 上的监听器**不净增长**
  （修复前 5 → 30，修复后稳定 4）
- **敌人意图一轮只掷一次**：重复 `rollIntents()` 不再推进 RNG、不改动已定意图；
  读档续战沿用快照里的意图，**不会走出与"没关过"不同的未来**
- **伤害统计口径**：中毒 / 狂战代价 / `loseHp` / 敌人自伤全部计入结算面板
  （敌人自伤算 `credit:'none'`，不记玩家的功劳）；单次统计不超过剩余生命
- **效果 DSL 与注释一致**：`dmgAll` 尊重 `hits`；玩家侧 `addCard` 真的能塞牌
  （旧代码只有敌人侧实现，照注释写卡会静默无效）；手牌塞不下时进弃牌堆且不超 10 张
- **状态标签**：标签上直接写出名称（虚弱/易伤/中毒…），长按看完整效果
- **UI 同步刷新**：商店购买后金币减少且标题不被覆盖、营火休息后血条更新、锻造弹层显示升级后的数值
- **运行期**：全程零未捕获 JS 错误

### 调试通道（可选）

`server.mjs` 带一个只在本地用的远程调试通道，供没有读屏/截屏权限时在真机上验证：

```
http://127.0.0.1:8765/index.html?agent=1
```

页面会回报界面状态（元素数量、手牌、意图、金币…）。也可以把一整套操作脚本编码进 URL，
用 `/app/open` 直接下发到手机浏览器执行并回报结果（见 `js/dev-agent.js`）。

`dist/abyss-deck.html` 里**不包含**这个通道。

## 界面自适应

所有内容装在 `#stage` 里，由 `fitStage()`（`js/core/util.js`）按视口整体缩放：

- **设计基准宽 430px**，CSS 里的尺寸都按这个宽度写
- 缩放到刚好铺满视口，**不缩小**（小屏 1:1），最大 3 倍
- 用 **`zoom` 而不是 `transform`** —— `zoom` 会触发重新排版，中文像素字体按目标字号光栅化、
  像素画按整数像素绘制，放大后不糊；`transform` 是把已经画好的位图拉伸，会糊
- 不支持 `zoom` 的老浏览器（Firefox < 126）自动退回 `transform`，仍然铺满，只是略微柔化
- 飘字 / 长按气泡 / 提示条这几层不参与缩放，用真实屏幕坐标定位，字号按 CSS 变量 `--k` 放大

这样在两种环境下都能看清：

| 环境 | 视口 | 缩放 | 效果 |
|---|---|---|---|
| 正常手机浏览器 | 412×915 | 1.0× | 铺满 |
| 桌面模式浏览器（如 MIUI 开「电脑版网页」） | 980×1755 | 2.19× | 铺满，物理尺寸与手机一致 |

**手牌会自动叠放**：牌多时按可用宽度算错开距离，露出每张牌的 2/3 以上（费用、名字、立绘都看得见），
不用横向滚动；超过 8 张才会真的需要滑动。

**卡面文字自动适配**：描述放不下时逐档缩字号（`fitCardText()`）。
实测 65 张普通版 + 60 张升级版在卡组/奖励/商店/手牌四个场景全部零溢出。
任何时候**长按任意卡牌**都能弹出放大版看完整效果。

**地图可以拖动**：`.map-wrap` 是真正的滚动容器（`overflow-y:auto` + `touch-action:pan-y`），
打开时会自动定位到「接下来能去哪」的那一批节点，上方留出余量；上下边缘有渐隐提示还能继续滚。
