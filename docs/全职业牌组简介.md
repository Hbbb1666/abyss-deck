# 全职业专属牌组简介

> 按 2026-10-13 的**新价值表**重新配平后的结果。
> 真源：`js/data/values.js`；逐张牌的"价值/预算"审计见 [卡牌价值审计.md](卡牌价值审计.md)。
>
> **怎么读"价值/预算"**：左边是这张牌按价值表算出来值多少点，右边是它这一档允许的额度。
> 两个数接近 = 配平到位；`▲` 表示超、`▼` 表示欠。"模型不计"= 它的效果无法折成点数（如"按护甲结算伤害"）。
>
> **终结牌**（每职业 1 张）单独成节：费用是 **N**（吃掉当前全部能量）、彩色流光边框、
> 有条件门、牌组唯一、出现权重低（约普通牌的 1/6）、参考价值 40。

## 价值表速览（本次重定的部分加粗）

伤害/护甲/生命 = 1 点 · 能量 = 3 点 · **抽牌 = 5 点**
**中毒/流血/虚弱/点燃 = 3 点** · **敏捷 = 3.5** · 荆棘 = 3 · 真理 = 5
**冰霜 = 4.5**（硬约束：只出现在 ≥2 费的寒冰法师牌上）
能量饱和 = 6.5 · **洞察 = 6.5** · **抵挡 = 6** · 壁垒 = 6
**力量 = 4（奥术法师 6）** · **易伤 = 4（奥术法师 5 / 暗影刺客 3.5）** · 再生 = 4（圣骑士 3.5） · **脆弱 = 4（奥术法师 5）**
放大器型：淬毒/血涌/强化 = 6 + 2.5×N · 备战 = 2 + 1×N
